# Inspiration and Scope

This skill is an original MicroTech synthesis. It does not vendor or copy an
external skill.

Ideas were studied from:

- Frontend Design (Anthropic): subject-grounded visual direction, two-pass
  plan/critique, anti-template typography and copy.
- Impeccable: Operate-mode restraint, design specificity, craft floor.
- UI-Taste (Uizze): anti-slop laws, product-specific composition.
- Taste Skill: app-screen observations about colour on data, flat surfaces and
  honest states.

What was deliberately changed:

- All visual decisions are driven by a resolved profile/target, not a fixed
  palette, panel or hero pattern.
- The output is a design plan for LVGL/embedded UI, not CSS or HTML.
- Motion and asset choices are capped by the target budget.
- The skill never treats the current MicroTech style as a universal baseline.
