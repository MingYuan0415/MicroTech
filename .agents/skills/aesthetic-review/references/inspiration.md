# Inspiration and Scope

This review skill is an original MicroTech synthesis; no external skill text is
copied.

Ideas studied:

- Impeccable: design-director critique, company/product specificity, craft
  floor.
- Design Review (sejas/ai-code-skills): screenshot-first review, severity
  levels, spacing/type/hierarchy/state rubric.
- UI-Taste (Uizze): anti-slop laws and product-specific composition.
- UX Heuristics: severity ranking and recovery checks.

Deliberate changes:

- Review is always against a resolved profile/target pair, never the current
  palette or panel.
- Profile-relative findings are separated from the universal floor.
- `style_audit.py` only checks what a widget tree can prove; composition and
  copy remain a visual/manual review.
