# Inspiration and Scope

This UX skill is an original MicroTech synthesis; no external skill text is
copied.

Ideas studied:

- Nielsen's ten usability heuristics and severity practice.
- Steve Krug: “Don't Make Me Think”, scanning, satisficing and the trunk test.
- Lean UX: hypothesis and experiment framing for product decisions.

Deliberate changes:

- The review is tied to the target's input capabilities, not a web or desktop
  keyboard model.
- Visual style is out of scope; style belongs to `visual-design` and
  `aesthetic-review`.
- The output separates product-flow, visual and implementation findings.
