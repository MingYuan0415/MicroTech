# Inspiration and Scope

This motion skill is an original MicroTech synthesis; no external skill text is
copied.

Ideas studied:

- Emil Kowalski: frequency gate, press feedback, short UI durations, restraint.
- Apple Design: response on touch-down, 1:1 tracking, interruptibility,
  spatial consistency and momentum.
- Design Motion Principles: motion audit and anti-slop checklist.
- UI-Taste: motion laws and the “delete the animation” default.

Deliberate changes:

- The target profile is the hard budget; the style profile is only ambition.
- Spring physics, blur, particles and full-screen image motion are explicitly
  excluded from the embedded implementation.
- Every motion plan is machine-checked before implementation.
